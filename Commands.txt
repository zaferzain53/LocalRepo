To use git locally in PC
do git config by going to git bash terminal in windows

On github portal add step will be removed and we can directly commit.


git config --global user.name "Syed"   -- typically the name of your git account or any name this will be set at global level
git config --global user.email "your-email@example.com" -- typically the name of your github email account.
git config --global credential.helper manager -- this is for caching or saving te credential

this will be stored in cat /c/Users/<your-username>/.gitconfig

From github web we can directly create a repo and create or commit file or folders or branch but if you want to work on 
two ways. 
1. create the repo maintain on git then cloning it and working with it in local with that repo
2. create the repo or the foldername in you local PC then commit it locally there then push it to github main.

1. Create a folder where you want to clone the repository the folder name is the repository
go inside the folder and run

-- git clone https:// paste the URL from the repo code in the github website

all the files will be cloned in the local folder.

because we did git clone a .git hidden folder will be created in the repo folder.

-- run ls -a or powershell ls -Force

then once the repository is cloned then check the status commands

-- git status on freshly cloned command.

it shows the file as untracked on the new file 
and if on the same cloned file if you change anything then it shows modified status
unmodified 
or staged when we add the file but did not commit yet then.

run command git add . this will make the status to staged and says changes ready to be committed.

git commit -m "Added new txt file"    -- this will commit the changes in the local folder

git push origin main   --- or you can write git push -u origin main  -- give it authorize for github for first time.

once git push -u origin main then we can simply put git push so next time it will not ask full line origin main.
